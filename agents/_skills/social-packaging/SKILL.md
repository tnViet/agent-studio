# Social packaging

The package is what the user copies when posting by hand. It must be accurate to the video, readable on a phone, and honest.

## Title (under 80 characters)
- Put the hook or the question first; the first 40 characters are what most feeds show.
- Use the topic words people would search for ("giao thoa sóng", not only "hiện tượng thú vị").
- Full Vietnamese diacritics, no ALL CAPS, at most one emoji, no claims the video does not support.
- Patterns: a question ("Vì sao hai sóng gặp nhau lại biến mất?"), a promise ("Hiểu giao thoa sóng trong 45 giây"), a surprise.

## Description (1 to 3 sentences)
What the viewer learns, in plain words, then one open question to invite comments. Take facts only from script.json.

## Hashtags (5 to 8)
- Mix: 1 to 2 broad (#hoctap, #khoahoc), 2 to 3 topic (#giaothoasong, #vatly12), 1 to 2 format (#shorts, #learnontiktok).
- No spaces; common Vietnamese practice is lowercase without diacritics.
- No unrelated trending tags.

## Formats to platforms (for the user's information)
| File | Use for |
|---|---|
| 9x16 | TikTok, Instagram Reels, YouTube Shorts, Facebook Reels |
| 4x5 | Instagram and Facebook feed posts |
| 1x1 | feed posts where square fits better |
| 16x9 | regular YouTube or a website |

## Self-check
- Title, description and tags match what is actually said and shown.
- package.json is valid UTF-8 JSON and every file path exists.
